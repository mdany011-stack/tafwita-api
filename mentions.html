Mentions legales

Editeur

TAFWITA est un service de gestion de file d'attente pour cabinets medicaux en Algerie.

Editeur : titulaire du statut auto-entrepreneur (ANAE, activite developpement logiciel / developpement web), Algerie. L'identite complete, le numero d'immatriculation ANAE et le NIF seront indiques ici des reception de la carte.

Contact : tafwitacontact@gmail.com

Objet du service

Le site permet aux patients de prendre un ticket a distance et de suivre leur tour. Le cabinet gere la file depuis une console web (telephone ou ordinateur) et peut afficher les numeros sur une tele. TAFWITA n'est pas un dossier patient informatise.

Hebergement actuel

Le site public (pages HTML, PWA) est heberge sur Cloudflare Pages, adresse https://tafwita.pages.dev/ (societe Cloudflare, Etats-Unis / reseau mondial).

L'interface de programmation (API) et la base sont hebergees chez Render (societe americaine). Adresse actuelle : tafwita-api.onrender.com.

Les e-mails automatiques d'inscription passent par Brevo (Sendinblue, Union europeenne) lorsqu'une cle API est configuree. L'adresse de contact Gmail transite par Google (Etats-Unis).

Ces hebergeurs sont hors d'Algerie. Un hebergement local (VPS algerien) est prevu des que l'identite legale (carte ANAE ou registre de commerce) est acceptee par un hebergeur local. Voir Demarches 18-07.
