Mentions legales

Editeur

TAFWITA est un service de gestion de file d'attente pour cabinets medicaux en Algerie.

Contact : tafwitacontact@gmail.com

Objet du service

Le site permet aux patients de prendre un ticket a distance et de suivre leur tour. Le cabinet gere la file depuis une console web (telephone ou ordinateur) et peut afficher les numeros sur une tele.

Hebergement

Le site vitrine est heberge sur GitHub Pages. L'interface de programmation (API) est hebergee chez Render.
